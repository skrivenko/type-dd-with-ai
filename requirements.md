# Заявка на временный пропуск

- Посетитель планирует прийти в офис компании. Для него заранее запрашивают временный пропуск.
- В некоторых случаях запрашивают дополнительные сведения о посетителе, например паспортные данные или цель визита.
- Служба безопасности может запретить конкретному посетителю проход в офис.

## Технические требования

- Использовать Type DD: разные статусы заявки представлены отдельными типами.
- Некорректный переход между статусами должен быть невозможен на уровне компиляции.
- Язык — Java; тесты — JUnit 5.
